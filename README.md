# Human → Alien Translator

A small web translator that converts human text into a fictional alien language.

## Features

* Human → Alien translation
* Unicode support
* Pure HTML, CSS and TypeScript
* No backend required
* GitHub Pages ready

[Open Human → Alien Translator](https://totldev.github.io/Human-to-alien-translator/)

## Run locally

```bash
npm install
npx tsc
```

Then open `index.html` in your browser.
